# RFM 기반 고객 세그먼트 분석

## 프로젝트 소개

고객의 구매 데이터를 기반으로 RFM 분석을 수행하고,
고객 세그먼트별 특성과 마케팅 반응을 분석한 프로젝트입니다.

## 분석 목적

- 고객의 구매 행동을 기반으로 고객군을 세분화
- 고객 세그먼트별 구매 특성 비교
- 세그먼트별 마케팅 반응 차이 분석
- 분석 결과를 바탕으로 마케팅 활용 방안 도출

## 주요 분석

- 데이터 전처리 및 탐색적 데이터 분석(EDA)
- RFM 지표 산출
- 고객 세그먼트 분석
- 세그먼트별 특성 비교
- 마케팅 반응 및 전환 분석

## 사용 기술

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
